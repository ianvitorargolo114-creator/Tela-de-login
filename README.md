# controle_financeiro

## Acesso ao painel

O painel exige cadastro e login. Nesta versão de demonstração, as contas são
armazenadas somente no navegador; cadastre-se em `login.html` e depois entre
com o nome, e-mail, telefone, CPF e senha escolhidos. A sessão termina ao
fechar a aba ou ao selecionar **Sair**.

Esta autenticação local não substitui um serviço de autenticação com backend
para proteger dados em produção.
